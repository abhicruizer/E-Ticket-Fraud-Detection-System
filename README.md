# 🎫 E-Ticket Fraud Detection System 
Project Link :: https://securetrail-ai.onrender.com

A secure and intelligent e-ticketing platform designed to prevent ticket fraud through real-time validation, QR code verification, two-factor authentication (2FA), and machine learning-based anomaly detection.

## 🚀 Features

- Secure user authentication with JWT & OTP verification
- Dynamic QR code generation and validation
- Real-time duplicate ticket detection
- Fraud detection using Machine Learning models
- PDF e-ticket generation
- Email/SMS ticket notifications
- Role-based access control (Admin, User, Operator)
- Responsive web interface

## 🛠️ Tech Stack

- Frontend: React.js, Bootstrap
- Backend: Node.js, Express.js
- Database: MySQL
- Authentication: JWT, OTP Verification
- Security: HTTPS, Role-Based Access Control
- ML: Isolation Forest for anomaly detection
- Tools: Docker, Git, Jenkins

## 📊 Project Objective

To enhance the security and reliability of digital ticketing systems by detecting and preventing fraudulent ticket purchases and usage through advanced analytics and secure ticket validation mechanisms.

## 🔒 Key Security Measures

- Two-Factor Authentication (2FA)
- QR Code Verification
- Duplicate Booking Detection
- Fraud Risk Scoring
- Audit Logging
